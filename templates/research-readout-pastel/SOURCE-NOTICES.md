Source author attribution still follows the named source page; this implementation does not claim authorship of the source design.

Changes: reconstructed 20 public preview layouts in their original order as native HTML text, CSS rules, SVG devices/diagrams and independent media slots; added a portable local navigation runtime; substituted fictional Fieldwork example copy and original product UI in placeholder frames. The local alignment demonstration is single-user and does not reproduce Figma's shared voting service.

Fonts: Implemented fonts selected by preview matching; source font not verified. DM Sans 300/400 and Roboto Mono 300 preserve the source rounded sans-serif main voice and monospaced metadata rail. Font files are embedded offline; the exact files carry SIL OFL 1.1 notices saved alongside the template.

Source screenshots are measurement references only; no slide screenshot is embedded as a background. Independent photographs, where used, are recorded separately below. Preview-compression color variations were measured from the public AVIF images; editable source paint values were not available at build time.

The percentage bars use the edited numeric text to set a common 7 px/% height. For low percentages in the six-column layout, number labels move above the fixed descriptions with a measured 16 px text-ink gap; zero-value bars have no visible outline. Both percentage layouts omit the outline when its rounded top edge would intersect the number or description text, keeping labels clear without changing the filled height. Default demo placement is unchanged. This is an HTML adaptation of the source layout, not an original Figma interaction.
