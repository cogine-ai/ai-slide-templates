## Distribution typography adaptation

This version embeds **Manrope variable TTF, version 4.505**, weights 200/300/400/500/700. The unmodified official font file comes from the [Google Fonts source directory](https://github.com/google/fonts/tree/main/ofl/manrope). Its applicable **SIL Open Font License1.1**, metadata and exact SHA-256 are included in `FONT-LICENSES/` and the HTML notice. The font file's copyright 2019 and the supplied license's copyright 2018 notices are retained.

The source's Cabinet Grotesk font is **not embedded or distributed**. Its [Fontshare ITF license](https://www.fontshare.com/licenses/itf-ffl) restricts repository and third-party template redistribution. Manrope is a disclosed visually close alternative under this repository's portability exception. It is not asserted to be the source font or to have identical glyph outlines.

CSS font metrics are calibrated per weight: size-adjust 92.9164%/95.4849%/92.4085%/95.7644%/91.8199% for weights 200/300/400/500/700, with ascent/descent/line-gap calibration to the source baseline rhythm. The original text-frame geometry and line heights remain. The unmodified Manrope font binary is used; these are CSS rendering descriptors, not a modified typeface.

An exact-source-font local research copy is preserved in the original workspace's ignored `outputs/restricted-template-studies/exact-font-2026-11-01/` directory. That copy is not included in the published bundle.

The original demo quote on page 11 is shortened to preserve the source quote frame and wrapping capacity with Manrope; source CSS sizes and line heights remain.
