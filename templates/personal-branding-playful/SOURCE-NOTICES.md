- **Savate Regular:** the source's original static design, matched against the [2015 Collectif We.ch OTF](https://github.com/CollectifWech/Savate), is retained unchanged. This is not the later 2025 redraw.
- **Poppins 500/600, version 4.004:** unchanged original font files remain. The foundry's **SIL OFL 1.1** and copyright notice are retained in the HTML and `FONT-LICENSES/poppins-OFL.txt`.
- **Unbounded700, variable TTF version 1.701:** this version uses the unmodified official [Google Fonts file](https://github.com/google/fonts/tree/main/ofl/unbounded), under its included **SIL OFL 1.1**, copyright 2022 The Unbounded Project Authors. Exact file SHA and metadata are in `FONT-LICENSES/`.

The source's Hanson Bold font is **not embedded or distributed**. Its exact source font only identified unspecified Creative Commons terms without a version or URL, so full standalone font redistribution permission was not established. Unbounded is a disclosed wide-caps alternative under the repository's portability exception. Its glyph outlines differ. CSS size-adjust 103.329022% and source-baseline ascent/descent calibration preserve the source text-frame geometry and wide-cap presentation voice. Font files are not modified.

The original-font research copy remains only in the original workspace's ignored `outputs/restricted-template-studies/exact-font-2026-11-01/` directory and is not part of this bundle.
