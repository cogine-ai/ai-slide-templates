Changes: reconstructed 35 public preview layouts in their original order as native HTML text, CSS rules, SVG devices/diagrams and independent media slots; added a portable local navigation runtime; substituted fictional Fieldwork example copy and original product UI in placeholder frames. The local alignment demonstration is single-user and does not reproduce Figma's shared voting service.

Fonts: Implemented fonts selected by preview matching; source font not verified. Inter 300/400 and Tinos Regular preserve the source sans-serif main voice and Times-like serif section titles. Font files are embedded offline; the exact files carry SIL OFL 1.1 notices saved alongside the template.

Source screenshots are measurement references only; no slide screenshot is embedded as a background. Independent photographs, where used, are recorded separately below. Preview-compression color variations were measured from the public AVIF images; editable source paint values were not available at build time.

The final inspiration page contains four isolated photographic regions cropped from source preview 36. They contain no slide captions or other slide text. Their individual original photographers and licenses have not been resolved; the Figma source attribution is retained and this limitation is explicit.
