## Typography and preview measurement

Implemented fonts are Inter 300/400 and Tinos Regular, selected by public-preview comparison; the original source font identity has not been verified. Actual embedded font files carry SIL OFL 1.1 notices in `FONT-LICENSES/` and the HTML.

Preview-compression color variations were measured from public images; editable source paint values were not available. Geometry and visual frames retain the measured template structure. The photography replacement changes the images within those existing frames, not the grid, fonts, palette, captions or navigation behavior. No Figma account or editable source file was used.
