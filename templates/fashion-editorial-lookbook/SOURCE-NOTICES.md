# Source and font notices

Design reference: **Editorial Layouts**, by Carmen Nácher, published on [Pitch](https://pitch.com/templates/Editorial-Layouts-0oSMjM3bXrVP4MnkDG674F9T).

The exact embedded fonts are **Fogtwo No5 Regular, version 0.87** (gluk; reserved font name FogtwoNo5), **Inter Regular and Bold, version 3.018;git-588b23468** (copyright 2020 The Inter Project Authors), and **Nunito Sans Regular, version 2.001** (copyright 2016 The Nunito Project Authors). Nunito Sans retains the source UUID family alias for six small credit numerals. All use the **SIL Open Font License 1.1**; unchanged source-served font bytes are embedded in the HTML. The full font copyright and license notices are retained in `template.html`. The newer Fogtwo No5 version 0.88 was inspected only as license evidence and is not the embedded font.

License sources: [Fogtwo No5 author](https://www.glukfonts.pl/font.php?font=FogtwoNo5), [Inter OFL](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt), [Nunito Sans OFL](https://github.com/google/fonts/blob/main/ofl/nunitosans/OFL.txt).
